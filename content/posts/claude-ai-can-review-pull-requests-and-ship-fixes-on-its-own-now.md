<p class="wp-block-paragraph">Anthropic is launching some new Claude AI features to help software engineers ship code. As part of a new Claude Ship product being announced today, Claude now can review, fix, and approve pull requests.</p>
<p class="wp-block-paragraph">Engineers have already been able to take advantage of Claude's code review capabilities thanks to the Code Review feature, which was announced <a href="https://claude.com/resources/articles/code-review">in March</a> and became generally available <a href="https://claude.com/resources/articles/code-review-is-now-generally-available">in October</a>. What's new alongside Claude Ship are the PR Steward and Claude Approvals agents, which are launching in beta today.</p>

<p class="wp-block-paragraph">Now you can generate, preview, and edit PDFs, Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code <a href="https://blog.google/innovation-and-ai/products/gemini-app/edit-files-directly/">directly within Google Gemini</a>. The new file editing capabilities are available starting today for all Gemini users, and while PDF previews/editing works on both the web and mobile, all other file formats are only in the web version for now.</p>
<p class="wp-block-paragraph">Google added support for <a href="https://www.theverge.com/ai-artificial-intelligence/920870/now-google-gemini-will-create-spreadsheets-pdfs-and-other-files-if-you-ask">generating and downloading files</a> in Gemini earlier this year, but now you can tweak those files without leaving the Gemini app. Google says you can expand documents to edit them in full-screen mode and highlight text in files to ask Gemini questions or prompt …</p>

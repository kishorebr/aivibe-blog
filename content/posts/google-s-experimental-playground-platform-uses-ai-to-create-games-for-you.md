                Google has launched a new AI-powered experimental gaming platform called Playground, which lets you create games without needing to know how to code or draw. It has an interface similar to most AI chatbots, where you can type in a prompt for the kind of game you want to build. You can also choose whether to create a 2D or 3D game and, for select genres, whether it's single-player or multiplayer. 

Google

While you can write your prompt from scratch, you can also remix some starter prompts or use guided support. After the initial output, you can shape the game mechanics, physics and graphics with further prompts. For example, if you're making a platformer, you can tell Playground to let the player double-jump so they can reach higher platforms a single jump can't reach.

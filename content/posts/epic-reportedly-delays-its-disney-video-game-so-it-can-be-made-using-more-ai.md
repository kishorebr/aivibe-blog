                Epic Games is going all in on AI for game development. The studio has been working on games for Disney, but sources told Bloomberg that its upcoming release has been delayed in order to use more AI for its creation. The publication reported that one of the game's directors informed the team that the project would be adopting an "AI first" production plan. "No more hand-written code," the internal message stated, as well as ordering all art for the project to be "generated with full AI workflows."
The publication's sources said this new approach was not universally well-received by the devs, with some employees allegedly hoping that the request wasn't totally serious. However, Epic Games has already been pushing a lot of generative AI tools into its Unreal Engine platform this year, so the directive seems pretty real.

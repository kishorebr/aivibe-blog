    Anthropic's Claude and Cowork will share memories about you now - unless you opt out
     
    Anthropic is merging Claude chat and Cowork memory, raising privacy questions about what AI remembers and if it's worth the tradeoff.
      Written by 
            David Gewirtz, Senior Contributing EditorSenior Contributing Editor  Aug. 25, 2026 at 10:00 a.m. PT                             Anthropic / ZDNETFollow ZDNET: Add us as a preferred source on Google.  ZDNET's key takeaways Claude chat and Cowork now share one memory system.Memory updates as you chat, with sensitive-data controls.The productivity boost comes with serious privacy tradeoffs.Today, Anthropic announced the merger of the memory systems for Claude chat and Claude Cowork."Starting today, the memory you use in chat is the same as in Claude Cowork. Now, wherever you work with Claude, it starts from what it already knows about you," said Anthropic. Memory is now two-way. What you do in Claude chat is remembered by Claude Cowork. What you do in Cowork is remembered in chat. It seems that what happens in Claude Code still stays in Claude Code. The company made no mention of Claude Code whatsoever in the announcement. When I asked, I was told this update is "focused on Claude Cowork and chat." Progress in implementing AI systems and services has been moving forward at warp speed, which some have taken to calling "AI speed." One of the side effects of this rapid pace of innovation is that experiments have turned into projects and then into products, often without the benefit of an end-to-end product plan. As a result, we've been seeing capabilities mirrored across products but not necessarily coordinated between them. Features appear in one implementation but mysteriously vanish in the next (ChatGPT desktop, I'm looking at you). We're also starting to see the consolidation of features.

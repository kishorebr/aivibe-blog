<p class="wp-block-paragraph">OpenAI's ChatGPT Atlas browser <a href="https://www.theverge.com/ai-artificial-intelligence/963654/openai-chatgpt-atlas-ai-browser-shut-down-sunset">is gone</a>, but now ChatGPT's <a href="https://chromewebstore.google.com/detail/hehggadaopoacecdllhhajmbjkdcmajg?utm_source=item-share-cb">Google Chrome extension</a> is getting some upgrades that allow it to use the browser tabs you already have open. With the extension installed, OpenAI says ChatGPT can now view your browser tabs when you tag Chrome in ChatGPT's web or desktop app, posting <a href="https://x.com/ChatGPT/status/2110823738531037651?s=20">a demo video</a> showing someone asking ChatGPT to compare the three tabs they have open with sofas they're considering.</p>

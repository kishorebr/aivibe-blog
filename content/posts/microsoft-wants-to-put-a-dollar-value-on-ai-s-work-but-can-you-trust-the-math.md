Earlier this year, Microsoft introduced Agent 365, its tool for tracking agents the way an HR department would normally track human employees. With Agent 365 Business Analytics, Microsoft is attempting to build an accounting system for AI labor. The system attempts to calculate the economic value of the work performed by agents compared with what the agents cost, and then provide a return on investment estimate.



How much value in real dollars are your agents producing?



If it works, this is some very cool stuff. Microsoft is trying to map labor-market economics onto AI usage data to create value estimates.

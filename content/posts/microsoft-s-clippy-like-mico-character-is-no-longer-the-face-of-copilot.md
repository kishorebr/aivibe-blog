<p class="wp-block-paragraph">Microsoft Copilot will no longer show its emotive yellow blob, Mico, when you use the chatbot's voice mode. In a <a href="https://support.microsoft.com/en-us/microsoft-365-copilot/frequently-asked-questions-about-retired-copilot-features">support page</a>, Microsoft says it's going to move Mico to its Learn Live platform, where the avatar will have "more to react to," <a href="https://www.geekwire.com/2026/farewell-mico-microsofts-cute-little-ai-blob-is-going-the-way-of-bob/">as reported earlier by <em>GeekWire</em></a>.</p>
<p class="wp-block-paragraph">Mico <a href="https://www.theverge.com/news/804106/microsoft-mico-copilot-ai-assistant-clippy">launched in Copilot's voice mode last October</a>, with Microsoft AI CEO Mustafa Suleyman pitching the avatar as a way to <a href="https://www.theverge.com/news/713715/microsoft-copilot-appearance-feature-age-mustafa-suleyman-interview">give the chatbot an "identity."</a> The blob would react to what you say in real-time, complete with facial expressions and animations.</p>

<p class="wp-block-paragraph">Mico joins <a href="https://the-microsoft-windows-xp.fandom.com/wiki/Office_Assistants">the long list</a> of virtual helpers that Microsoft has retired over the years, like Clippy, Cortana, and Rover …</p>
